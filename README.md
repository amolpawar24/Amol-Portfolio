# 🧩 Data-Driven Projects

Projects are maintained through a centralized data file.

```text
src/data/projectsData.ts
```

Each project contains information such as:

```ts
{
  id: 1,
  image: "/assets/images/projects/example.png",
  title: "PROJECT NAME",
  description: "Project description",
  categories: [
    "React",
    "JavaScript"
  ],
  tech: [
    "fab fa-react",
    "fab fa-js"
  ],
  liveDemo: "https://example.com",
  code: "https://github.com/example"
}
```

### Data separation

The project uses two different concepts:

**`categories`**

Used for project filtering.

```text
HTML
CSS
JavaScript
React
Next.js
Node.js
...
```

**`tech`**

Used for displaying technology icons.

```text
fab fa-react
fab fa-js
fab fa-html5
...
```

This keeps filtering logic independent from the visual representation of technologies.

# 💻 Getting Started

## Prerequisites

Make sure the following are installed:

* Node.js
* npm
* Git

Check your installed versions:

```bash
node -v
npm -v
git --version
```

---

# 📥 Installation

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
```

Move into the project directory:

```bash
cd amol-portfolio
```

Install dependencies:

```bash
npm install
```

---

# ▶️ Run Development Server

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

# 🏗️ Production Build

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```

If future versions of the portfolio require external services such as APIs, email services, analytics, authentication, or databases, environment variables can be stored in:
