# 📌 Project Overview

Portfolio 5 is a modern personal portfolio website developed using the Next.js ecosystem.

The project is designed to present:

- Professional profile
- Technical skills
- Development experience
- Projects
- Services
- Contact information
- Resume
- Professional journey

The application uses a component-based React architecture with TypeScript and SCSS for maintainable and scalable frontend development.
